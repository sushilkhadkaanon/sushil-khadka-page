links: []

The app generates image captions and uses vision-language models to extract structured JSON from PDF content. It retrieves relevant material and uses retrieval-augmented generation to answer questions.

The implementation uses LangChain, Hugging Face, Elasticsearch, and Amazon S3 for document retrieval and answer generation.
